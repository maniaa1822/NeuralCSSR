# Neural CSSR: Epsilon machine discovery using AR transformers as oracles

*Discovering epsilon machines the minimal predictive models of sequential processes using transformers and information theory*

## What are we recovering from the transformer?

Imagine you're watching a seemingly random sequence of coin flips: 0, 1, 0, 0, 1, 1, 0... Is there a hidden pattern? Could this sequence be generated by a simple state machine with rules you haven't discovered yet?
Turns out that there is, always.
Every sequence has its epsilon machine.

This is the fundamental challenge of **causal state discovery**: given an observed sequence, can we uncover the minimal hidden state machine that generates it? This problem appears everywhere from analyzing neural spike trains in neuroscience to modeling financial markets and understanding language patterns.

The mathematically optimal solution comes from **computational mechanics**, which gives us **epsilon machines** (ε-machines): the smallest possible state machines that capture all predictive information about a process. They're both minimal (using the fewest states) and optimal (capturing everything that matters for prediction).

The traditional, classical algorithm for discovering these machines, called **CSSR** (Causal State Splitting Reconstruction), is incredibly brittle, as it is based on counting to estimate probabilities and thresholding of equivalence tests, and therefore has no "interal representation" of the underlying process.

## Why Classical CSSR is Impractical

Classical CSSR *can* recover correct epsilon machines but only with **perfect parameter tuning that requires foreknowledge of the process**.

### 1. The L-Explosion Problem
The algorithm's critical parameter is **L** (maximum history length). in practice, this is not known and needs to be inferred from the data.
- **Too small L**: Miss long-range dependencies, under-split states
- **Too large L**: Spurious state explosion discovered states grow exponentially with L

**Example trajectory for Seven-State Machine:**
```
L=2  → 3 states (under-split, missed structure)
L=4  → 7 states (correct! but you need to know this is right)
L=6  → 15 states (over-split, spurious distinctions)
L=8  → 31 states (explosion continues...)
```

Without knowing the true memory length (which is what you're trying to discover!), how do you choose L? Too small and you fail; too large and you get overwhelmed with spurious states.

### 2. The Foreknowledge Requirement
Optimal parameters vary wildly across processes:
- **Golden Mean**: L=2, α=0.001 works perfectly
- **Even Process**: L=20, α=0.05 required (but still doesn't converge!)
- **Seven-State**: L=4, α=0.01 works, but L=5 gives 12 states

There's no principled way to choose these without already understanding the process structure. Classical CSSR requires you to know what you're trying to discover.

### 3. Statistical Test Brittleness
ok given that the test is based on counts, why not just use the transformer to estimate probabilities directly?
The algorithm uses chi-squared tests that assume integer counts. When adapting to continuous probability estimates from neural networks, arbitrary scaling factors cause unpredictable behavior.
#### The Classical Chi-squared (χ²) Test in CSSR

At the heart of classical CSSR is a statistical hypothesis test: the **chi-squared (χ²) test for independence**. Here’s how it works:

1. **Observed Frequencies:** For each "history" (context string) in the data, CSSR counts how often each symbol follows it. This produces an *empirical distribution* of next symbols for that specific history.
2. **Test for Equivalence:** To determine if two histories should be assigned to the same causal state, CSSR compares their empirical next-symbol distributions.
3. **Significance via χ²:** The algorithm computes a χ² statistic:
    - It sums `(observed count - expected count)² / expected count` across all outcomes.
    - If this value is *less* than a threshold (set by significance α), the histories are declared **equivalent**—their future behaviors are statistically indistinguishable.

**Why is this brittle?**
- The test **assumes counts** (integers) that follow known statistical properties.
- If the number of occurrences is low or data is sparse, results are highly unstable.
- The test *cannot* be directly applied to probabilities (e.g., from neural models), because probabilities are not counts—the distribution of the statistic is totally different.

**Example (Toy Case):**
Suppose:
- History "01" is followed by "0" 8 times and "1" 2 times.
- History "10" is followed by "0" 5 times and "1" 5 times.

The χ² test helps decide if "01" and "10" produce the same future distribution, or if they represent different states.

**But:** If we use a neural network's *probability* (like 0.8 for "0", 0.2 for "1"), plugging these into χ² makes no sense. The usual test’s assumptions break down, and results become unreliable. This is a major limitation when trying to modernize CSSR with neural oracles.

**The result?** A beautiful theory with an implementation that requires expert tuning for each new process impractical for automated discovery.This is why we need to use the transformer as an oracle and formulate a new test that is based on the transformer's predictions.

## Our Solution: Neural CSSR

We present **Neural CSSR**, a robust approach that replaces classical CSSR's brittle statistical tests with neural probability estimation and information-theoretic clustering.

### The Core Innovation

Instead of counting frequencies in data (which fails for rare patterns), we:

1. **Train a transformer** to predict next symbols from history
2. **Use neural probabilities directly** without converting to counts
3. **Cluster histories** using Jensen-Shannon (JS) divergence on probability distributions
4. **Discover minimal contexts** through backward stability analysis

### The Three-Stage Algorithm

**Stage A: Emission Clustering with Backward Stability**

This is where we leverage the transformer's real power: **attention-based context selection**.

Transformers don't treat all tokens equally they learn to attend to the relevant parts of context for prediction. We exploit this by testing backward stability: for each history like "00100110", we ask whether shorter suffixes ("10", "110", "0110"...) produce the same predictions.

This is profound because:
- The transformer has already learned what matters for prediction through attention
- We're discovering the **minimal sufficient statistics** the model actually uses
- A history "00100110" and another "11000110" might both reduce to "10" if that's all that matters
- This gives us true causal states, not just similar-looking histories

After finding minimal contexts, we cluster them by emission distribution using JS divergence. Histories that predict "0 with 95% probability, 1 with 5%" belong to the same causal state.
**How do we compare two histories? (Jensen-Shannon Divergence)**

Instead of χ², Neural CSSR uses **Jensen-Shannon (JS) divergence** to measure how different two histories' neural emission distributions are. For two probability distributions \( P \) and \( Q \) (for example, "what's the chance of 0 or 1 after this history"), JS divergence is:

1. Take the average distribution \( M = 0.5 \times (P + Q) \).
2. Compute how "surprised" \( P \) and \( Q \) each are by \( M \) (using something called KL-divergence).
3. JS divergence is the average surprise:
   \[
   JS(P, Q) = 0.5 \times KL(P\,||\,M) + 0.5 \times KL(Q\,||\,M)
   \]

- JS divergence is always between 0 (identical) and 1 (for binary symbols, maximally different).
- If two histories produce nearly the same neural predictions, their JS divergence will be close to 0—so they likely belong to the same causal state.

This lets us cluster histories *directly on the smooth neural probabilities*—no counts or ad-hoc significance tests needed.


**Example (Seven-State Machine):**

We tested this on the Seven-State Machine, a standard benchmark for causal state discovery.

```
Initial histories sampled: ["0001", "1001", "101", "100", "000", "11", "10"]

After backward stability (suffix minimization):
  "0001" → "0001" (minimal, triggers state "aaab")
  "1001" → "1001" (minimal, triggers state "baab")
  "101"  → "101"  (minimal, triggers state "bab")
  "100"  → "100"  (minimal, triggers state "baa")
  "000"  → "000"  (minimal, triggers state "aaa")
  "11"   → "11"   (minimal, triggers state "bb")
  "10"   → "10"   (minimal, triggers state "ba")

After emission clustering (Stage A, using true emission parameters from the 7-state machine):
  Cluster 1: ["bb"]      → P(0)=0.94, P(1)=0.06
  Cluster 2: ["aaa"]     → P(0)=0.19, P(1)=0.81
  Cluster 3: ["aaab"]    → P(0)=0.19, P(1)=0.81
  Cluster 4: ["ba"]      → P(0)=0.56, P(1)=0.44
  Cluster 5: ["bab"]     → P(0)=0.25, P(1)=0.75
  Cluster 6: ["baab"]    → P(0)=0.75, P(1)=0.25
  Cluster 7: ["baa"]     → P(0)=0.56, P(1)=0.44

Result: 7 emission clusters (one per true causal state)
```

**Stage B: Conditional Refinement**

Look deeper: histories might have similar immediate predictions an the same suffix length but different long-term behavior. We compare multi-step "rollouts" to catch these cases two states might emit similarly now but diverge over future trajectories.Note that this stage is not necessary for the seven-state machine, as it is already minimal from the backward stability test.

**Example (Seven-State Machine):**
```
Stage A produced a cluster: ["0010", "0110"]
Both predict: P(next=0) ≈ 0.75

But 2-step rollout reveals difference:
  "0010" → P(00)=0.60, P(01)=0.15, P(10)=0.20, P(11)=0.05
  "0110" → P(00)=0.55, P(01)=0.20, P(10)=0.15, P(11)=0.10

JS divergence (2-step) = 0.032 bits > threshold (0.001)

Split into:
  Cluster 2a: ["0010", ...] (state "aaab")
  Cluster 2b: ["0110", ...] (state "aab")

Result: Refined to 7 precise clusters
```

**Stage C: Functional Remerging**

Merge states that are functionally identical critical for processes with infinite memory like the even process. Different minimal contexts might still represent the same functional state (e.g., "even parity" regardless of specific history length).

**Example (Even Process):**
```
After Stage B, we have many "even parity" states:
  State A: ["", "11", "1111", "111111", ...] (even count of 1s)
  State B: ["1", "111", "11111", ...] (odd count of 1s, minimal context "1")
  State C: ["11", "1111", ...] (even count, minimal context "11")
  State D: ["111", ...] (odd count, minimal context "111")
  ...

Test functional equivalence:
  States A and C: Same emissions, same 2-step rollouts → MERGE
  States B and D: Same emissions, same 2-step rollouts → MERGE

Final result: 2 functional states + 1 boundary state
  State "even": All even-parity histories
  State "odd": All odd-parity histories
  State "start": Empty history (boundary case)
```

## Benchmark Results: Perfect Model Distillation

We tested Neural CSSR on two challenging benchmark processes, treating the task as **distilling a neural network into an interpretable symbolic epsilon machine**.

### Even Process (Infinite Memory!)
Tracks parity of 1s seen requires infinite memory since you must remember an unbounded count.

**Transformer:** Successfully learned the infinite-memory dependency, achieving near-optimal loss

**Classical CSSR with optimal tuning**:
- Discovers 8-15 states depending on exact parameters
- State count grows with L
- Requires trying many L values to find what works "best" 

**Neural CSSR (single parameter set, L=5-6)**:
- Successfully identifies functional equivalence 3 states (2 parity + 1 boundary), 100% purity
- **No L-explosion**: backward stability finds minimal contexts automatically, tested up to L=32
- **The discovered epsilon machine exactly recovers the transformer's loss** ✓
- Perfect distillation: symbolic machine matches neural model loss exactly

### Seven-State Human (Complex Finite Memory)
A complex machine from human subject experiments with intricate suffix structure and stochastic emissions.

**Transformer:** Achieves excellent performance, approaching the theoretical entropy limit of the stochastic process

**Classical CSSR trajectory (varying L):**
```
L=2  → 3 states (missed structure)
L=4  → 7 states ✓ (correct with α=0.01, but how would you know?)
L=5  → 12 states (spurious over-splitting begins)
L=6  → 18 states (explosion accelerates)
```
Requires expert foreknowledge to choose L=4 and stop there.

**Neural CSSR (L=5-6, single threshold)**:
- **Perfect state recovery**: 7 states, 100% purity
- **No manual tuning**: backward stability prevents spurious states from L
- Works robustly across L=5, L=6, L=7 and beyond without explosion
- **The discovered epsilon machine exactly recovers the transformer's loss** ✓
- Perfect distillation: symbolic machine preserves neural model's predictive distribution exactly

### The Model Distillation Insight

This is profound: **Neural CSSR performs lossless distillation of neural networks into symbolic epsilon machines**.

The recovered epsilon machines don't approximate the neural model they **exactly match** its predictive distributions. This means:
- We extract a finite-state symbolic model with identical behavior
- The distilled model is fully interpretable (explicit states and transitions)
- We preserve all predictive information from the neural network
- The result is both minimal (fewest states) and optimal (captures everything predictive)


## The Design Journey: Why Use Models as Probability Oracles?

What about looking at the internal representations of the transformer? Our first instinct was natural: **cluster the transformer's hidden representations directly**. After all, if the model has learned causal states, shouldn't they be visible in the internal activations?

### Attempt 1: Direct Representation Clustering (Failed)

We collected hidden states from the final transformer layer and tried clustering them by ground-truth epsilon state.

**[Figure: t-SNE visualization of hidden states colored by ground truth epsilon state]**
*Hidden representations show poor state separation despite accurate predictions*

The results were discouraging:
- **Silhouette score: 0.158** (poor clustering structure)
- **Participation ratio: ~1.0** (information collapsed to ~1 dimension)
- **State purity: 66.8%** (highly entangled representations)
- **Mutual information: 0.271 bits** (weak state encoding)

Even with PCA, UMAP, and t-SNE, the states remained hopelessly entangled. Yet the model predicted perfectly!

### The Pivot: Hidden States ≠ Causal States

This failure led to a crucial insight: **epsilon machines are defined by functional behavior (what they predict), not representational structure (how they encode it)**.

The same epsilon machine has infinitely many valid internal representations. Neural networks distribute information across dimensions in complex, entangled ways. This is fine predictive distributions are invariant to representation choices.

### Attempt 2: Model as Probability Oracle (Success!)

Instead of looking inside the model, we use it as a **black-box probability estimator**. For any history, query the model for next-token probabilities, then cluster histories by these output distributions.This could also be done with different oracle models like LSTMs or RNNs in principle.

**[Figure: JS divergence heatmap]**
*Jensen-Shannon divergence between history pairs, grouped by ground truth epsilon state*

This immediately revealed clear structure:
- **Within-state pairs**: JS divergence ≈ 0.001–0.01 bits (near-identical predictions)
- **Between-state pairs**: JS divergence ≈ 0.1–0.5 bits (clearly distinct predictions)
- **Clean block diagonal structure** aligning with ground truth states

### The Role of History Length (L)

A critical question: how long must histories be to distinguish states?

**[Figure: JS divergence vs history length L]**
*Divergence between different epsilon states increases with context length*

The plot shows:
- **Short contexts (L=1–2)**: States may be confused (insufficient context)
- **Medium contexts (L=4–6)**: Divergence plateaus (sufficient for most states)
- **Long contexts (L>6)**: Diminishing returns (backward stability finds minimal L per state)

This motivated our **backward stability test**: find the shortest suffix for each history that preserves predictions. Often "10" is sufficient even when the full history is "00100110".

### Why This Works: Functional Equivalence

Causal equivalence is fundamentally about **what futures are possible**, not **how the model represents context**. Two histories are in the same epsilon state if and only if they have identical conditional distributions over all futures:

```
P(future | past = h₁) = P(future | past = h₂)  ∀ futures
```

By clustering output distributions, we directly measure this functional equivalence. The model's internal representation can be arbitrarily complex we only care that functionally equivalent histories produce identical predictions.

**[Figure: Comparison of approaches]**
*Left: Clustering hidden states (fails). Right: Clustering output distributions (succeeds)*

This aligns perfectly with epsilon machine theory: causal states are equivalence classes of **predictive behavior**, not representational similarity.

## Conclusions and discussion

1. **Transformer attention encodes causal structure implicitly.** By testing backward stability, we extract the minimal contexts transformers actually attend to for prediction revealing the causal states they've discovered.

2. **Neural networks can discover interpretable structure**, not just make predictions. They bridge deep learning and computational mechanics.

3. **Information theory beats statistical testing** for clustering. JS divergence provides robust, parameter-free comparison of probability distributions.

4. **Functional behavior matters more than internal representations.** We should judge models by what they predict, not how they represent information internally.

5. **Infinite memory is tractable** with the right approach. Functional equivalence detection lets us handle processes that stymied classical methods.

## What's Next? From Discovery to Foundation Models

While we don't need clean hidden representations for discovery, improving them, i.e. using additional losses of architectural changes could be an insteresting new direction. 
Multitask learning could be a waty to impove invaraince properties of the representations just like augmentations do for images: using Neural CSSR as a teacher to train DINOv2-like foundation models for causal structure.

### Current Results: Multitask Learning Improves Representations

We augmented standard language modeling with auxiliary heads that predict epsilon states, graph distances between states, and state transitions. The results show dramatic improvements: state prediction accuracy jumps from 89.3% to 97.7%, distance prediction from 32.9% to 98.5%, while language modeling loss remains unchanged. More importantly, multitask models show superior out-of-distribution robustness when we perturb data distributions through symbol swaps or transition noise, these representations adapt more effectively with simple calibration.

These multitask heads do more than improve accuracy they enforce a crucial property: **causal states become linearly decodable**. States, transitions, and emissions can all be predicted by simple linear transformations of the latent representation. This suggests the model is learning a structured latent space where causal relationships are geometrically organized.

### DINO for Sequences: Learning Invariant Causal Structure

This multitask approach hints at something more ambitious: pretraining a universal causal-state encoder across many epsilon machines. Just as DINOv2 learns visual representations from augmented image crops, we can learn causal-state representations from augmented sequence views.

The pipeline starts by running Neural CSSR on diverse processes (varying states, memory lengths, alphabet sizes) to discover their epsilon machines. These discoveries become teacher labels for a foundation model **supervision for free**, with no hand-labeling needed. The discovered epsilon machines tell us which histories belong to the same causal state.

The key innovation is **causal augmentations** transformations that preserve epsilon-state identity just as image crops preserve object identity. Suffix variations create different left contexts that map to the same state. Path diversity generates different trajectories through the state graph that end at the same state. Alphabet permutations (swapping 0↔1) preserve structure while changing surface form. Light perturbations add emission and transition jitter while maintaining functional equivalence.

With these augmentations, we train a self-supervised encoder where augmented views of the same causal state cluster together, exactly like DINO's approach with image crops. The teacher-student dynamics learn **invariant representations of causal structure**: the student encoder learns that a causal state remains invariant under suffix truncation, path diversity, and alphabet permutations. The representation captures what's essential for prediction the functional equivalence class while discarding superficial details like specific left context or symbol labels. This forces the model to discover true causal structure rather than memorizing surface patterns.

Adding multitask heads (as linear decoders for states, transitions, emissions) ensures the latent space remains interpretable. The result is a universal encoder that maps any sequence to a space where causal states are linearly separable, generalizes across processes without per-machine training, and enables zero-shot discovery through simple encode-and-cluster operations. This would transform Neural CSSR from a per-machine discovery tool into a **foundation model for causal structure**.

### Open Questions

**Compositional generalization** remains a key challenge: if we train on subgraphs of the 7-state machine (treating them as separate processes), can the encoder compose learned structures when faced with the full machine? This tests whether the model truly understands causal building blocks.

**Infinite memory processes** pose theoretical puzzles: how can finite-dimensional embeddings represent processes requiring unbounded memory? What trade-offs exist between latent dimensionality and approximation quality?

**Bootstrap convergence** is unexplored: does the iterative loop (discover structure → train encoder → better discovery) converge? Under what conditions? This could enable progressively better causal understanding through self-improvement.

**Machine-level embeddings** offer another frontier: representing entire epsilon machines as single vectors for retrieval, interpolation across process families, and understanding structural similarity at the whole-system level.

### Real-World Impact

Beyond benchmarks, foundation models for causal structure could transform how we analyze temporal data. In neuroscience, they'd enable discovery of neural state dynamics from spike trains and identification of regime shifts in brain activity. Financial applications include market regime identification, structural break detection, and interpretable trading state machines. Climate science could use them to discover causal patterns in time series and identify tipping points through structural changes. Biological applications span gene regulatory network analysis and cellular state transition modeling.

## Technical Details

For those interested in the mathematical foundations:

**Jensen-Shannon Divergence**: Our key clustering metric
```
JS(P, Q) = (1/2)[KL(P||M) + KL(Q||M)]
where M = (P + Q)/2
```

**Properties:**
- Symmetric: JS(P,Q) = JS(Q,P)
- Bounded: 0 ≤ JS(P,Q) ≤ 1 (with log base 2)
- Metric: √JS(P,Q) is a proper distance metric
- Continuous in both arguments

**Causal Equivalence**: The foundation of epsilon machines

Two histories h₁ and h₂ are causally equivalent if they have identical predictive distributions over all possible futures:

```
P(future | past = h₁) = P(future | past = h₂) for all futures
```

This equivalence relation partitions all possible histories into causal states each representing a unique predictive "mode" of the process.

**Complexity Measures:**
Statistical complexity C_μ = H[states] represents the entropy of state distribution. Entropy rate h_μ captures average uncertainty per symbol. Epsilon machines minimize C_μ for a given h_μ, achieving optimal predictive compression.
